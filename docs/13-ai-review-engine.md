# UX Review Companion — AI Review Engine

> Defines how UX Review Companion transforms a dashboard
> screenshot into an evidence-backed UX review.

---

# 1. Purpose

The AI Review Engine coordinates the complete UX review process.

Its responsibility is to move from:

> Dashboard screenshot

to:

> Evidence-backed, prioritized UX review.

The review should not jump directly from image to recommendation.

It follows a structured reasoning process in which each stage
provides information required by the next stage.

---

# 2. Review Philosophy

The conceptual review model is:

```text
Understanding
      ↓
Evidence Collection
      ↓
Evidence Validation
      ↓
Finding Generation
      ↓
Insight
      ↓
DES
      ↓
Recommendation
```
