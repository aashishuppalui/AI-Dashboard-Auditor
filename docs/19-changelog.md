# v0.1.0 — Core AI Review Pipeline

Status: ✅ Complete

The initial MVP established the core AI-powered dashboard review
experience.

### Added

- Dashboard screenshot upload
- Dashboard validation
- Dashboard Understanding Engine
- Observable Evidence Engine
- Highest-Impact Finding Engine
- Decision Effectiveness Score (DES)
- Priority Actions Engine
- Executive Overview
- Structured Review Pipeline
- Review UI
- Local review storage
- Basic product analytics
- Lightweight review feedback

### Core Review Flow

```text
Dashboard Screenshot
        ↓
Dashboard Validation
        ↓
Understanding
        ↓
Evidence
        ↓
Highest-Impact Finding
        ↓
DES
        ↓
Priority Actions
        ↓
Review
```
